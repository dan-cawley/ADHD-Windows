# Parent-First Sprint Plan

This plan focuses the product on parents of kids with ADHD first, with homeschool support as the next layer.

## Sprint 1: Trust And Clarity

Goal: make the app feel understandable and safe for a parent on first use.

- Show quest source clearly everywhere important:
  - `Parent Added`
  - `Student Added`
  - `Class Imported`
- Keep imported class quests visibly separate from student-created quests.
- Make locked behavior explain itself in plain language.
- Keep student-created quests clearly lower-trust and lower-reward.
- Reduce places where the parent has to guess why a quest can or cannot be edited.

## Sprint 2: Parent Workflow

Goal: let a parent set up real daily use fast.

- Make adding a quest extremely fast.
- Add recurring routines for chores, homework, and daily habits.
- Improve the `Today` view for a short, focused task list.
- Make first-run setup lead quickly to the first completed quest.
- Make parent controls simple instead of highly customizable.

## Sprint 3: Kid Motivation

Goal: keep the child engaged without making the system confusing.

- Tighten completion feedback and reward presentation.
- Make pet and gear progress easier to understand at a glance.
- Improve streak and progress visibility.
- Remove unclear or low-value reward text.
- Keep progression satisfying without rewarding fake work.

## Sprint 4: Homeschool Support

Goal: support real school workflows for families already using calendars.

- Make joined class calendar setup easier to understand.
- Improve import reliability and duplicate handling.
- Group imported work more clearly by class or subject.
- Make quizzes and tests feel meaningfully different from normal reminders.
- Improve parent visibility into what came from school versus home.

## Sprint 5: Paid Product Readiness

Goal: make the app ready to sell to the niche cleanly.

- Tighten onboarding copy and parent messaging.
- Decide what stays in free versus paid.
- Add more confidence-building help for parents.
- Polish high-traffic screens before expanding features.
- Avoid broad classroom features until parent retention is strong.
