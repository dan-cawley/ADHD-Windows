# Must-Keep Feature List

This list captures the strongest ideas from the current app that should be preserved or consciously rejected during the rebuild.

## MVP Candidates

- Quick capture with very low friction
- Today-focused quest list
- Due dates with overdue handling
- Morning review for overdue and carried quests
- Subquests and task breakdown
- Positive completion feedback
- XP and coins
- Bulk complete and bulk discard actions
- Reward summary flow that does not constantly interrupt task execution
- Save backup import/export

## Strong Retention Features

- Pet progression
- Weekly boss map
- Item preview and collection loop
- Active streak visibility
- Owned gear bonuses without manual equip friction

## Rebuild Guidance

- Default MVP recommendation: `Capture + Quests/Today + Review + Rewards + Backup/Restore`
- Recommended phase-two gate: add `Familiar` and `BossMap` only after the MVP loop feels sticky without excess UI weight
- Keep coin rewards and positive feedback in MVP because they directly reinforce task completion
- Keep reward presentation separate from reward mutation so the loop stays testable and quiet by default
